---
description: Ejecuta lint, build y test del frontend y resume el resultado
---

Ejecuta, en este orden y desde `src/frontend`, los tres comandos siguientes.
Corre los tres aunque alguno falle:

1. `npm.cmd run lint`
2. `npm.cmd run build`
3. `npm.cmd run test`

Luego resume en una tabla el resultado de cada uno (aprobado o fallido, número
de errores y de advertencias) y cita los mensajes relevantes de los que
fallen.

No corrijas nada automáticamente: no edites archivos ni instales paquetes.
Solo informa.
